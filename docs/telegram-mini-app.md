# Telegram Mini App

Telegram необязателен: обычный сайт и прямые ссылки/QR комнаты работают без бота.
Миниапп использует тот же React, API и WebSocket. При открытии внутри Telegram
сервер проверяет подпись `initData` и показывает имя/аватар участника.

## Настройка после публикации сайта

1. Создайте бота в @BotFather, включите Main Mini App и укажите публичный
   HTTPS-адрес сайта, например `https://music.example.com`.
2. В серверном `.env` задайте:

```dotenv
TELEGRAM_BOT_TOKEN=your-private-bot-token
TELEGRAM_WEBHOOK_SECRET=your-random-secret
TELEGRAM_MINI_APP_URL=https://music.example.com
CORS_ORIGINS=["https://music.example.com"]
```

Секрет webhook — случайная строка из букв, цифр, `_` и `-`, до 256 символов.
Её можно сгенерировать на своём компьютере:

```sh
python3 -c 'import secrets; print(secrets.token_urlsafe(32))'
```

3. Примените окружение и настройте существующего бота. Следующая команда
   изменяет меню, команды и webhook **бота из указанного токена**:

```sh
docker compose up -d --wait
docker compose exec -T api python - < infra/configure_telegram.py
```

Скрипт получает секреты из окружения контейнера. Токен не попадает во frontend
или командную строку. Отдельный polling-процесс не нужен: `/start` и `/help`
обрабатываются защищённым webhook того же API.

4. В @BotFather проверьте Main App URL: его нельзя изменить этим скриптом.
   Откройте приложение кнопкой в чате бота и создайте комнату.

## Приглашения и авторизация

QR и кнопка копирования содержат прямую ссылку вида
`https://music.example.com/?lobby=<id>`, чтобы гость мог войти через браузер.
Вход по `tgWebAppStartParam=l_<id>` также поддерживается, если приглашение
было сформировано через Main Mini App.

Если комната создана внутри Telegram, управление Main привязано к аккаунту
создателя. Для восстановления управления откройте её тем же Telegram-аккаунтом.
Обычные гости могут входить через сайт и добавлять треки без Telegram.
При отсутствии `username` показывается имя, без фото — первая буква имени.

Срок валидности `initData` — до 24 часов: после истечения откройте Mini App
заново. Перезапуск API очищает комнаты и сессии Яндекса. Telegram-профиль
восстанавливается при новом входе, но сама комната после рестарта не сохраняется.

При смене домена обновите `SITE_ADDRESS`, `CORS_ORIGINS`,
`TELEGRAM_MINI_APP_URL`, примените Compose, повторите настройку бота и измените
Main App URL в @BotFather. Реальный вход и воспроизведение в мобильном WebView
проверяются вручную: CI не использует ваш Telegram-аккаунт или бота.
