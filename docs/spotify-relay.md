# Экспериментальная передача звука Spotify

Один участник с Premium открывает комнату в Chrome/Edge на компьютере,
нажимает «Транслировать Spotify гостям», выбирает вкладку Prada Sound
и включает передачу её звука. Если транслятор — гость, хост подтверждает его.
Для автоматической очереди захватывается именно Prada Sound, не отдельный Spotify.
Гости включают «Слушать вместе»; у них нет Spotify iframe и не нужен Spotify-токен.

Хост сохраняет skip/reorder/remove и отправляет play/pause/seek транслятору.
Транслятор сообщает позицию и окончание только текущего Spotify-элемента.
Повторное ended не пропускает следующий трек. Получатели не перематывают поток
для синхронизации. На Яндексе и YouTube поток отключён и работает прежний плеер.
Мешап Spotify через Embed не реализован. Максимум 20 получателей на комнату.

WebRTC отправляет только аудиодорожку; захваченные видео, пароли и токены
провайдеров не передаются. Аудио защищено DTLS-SRTP, на сервер не записывается.
Как и у любого воспроизводимого звука, полностью запретить запись у получателя нельзя.
Подтверждённый пользователем захват не гарантирует работу во всех браузерах;
на смартфоне можно принимать звук, источник захвата — компьютер.

TURN — резерв для разных сетей. Установить перед обновлением API:

```sh
python3 infra/configure_relay.py --public-ip PUBLIC_IPV4
docker compose --profile relay up -d turn
```

Скрипт создаёт приватный `.local/turn/turnserver.conf` и дополняет `.env`.
Открыть TCP/UDP 3478 и UDP 49160–49359 в firewall хостинга. Контейнер coturn
использует host network, один relay thread, лимит RAM 96 MiB, квоты трафика
и авторизацию. Приватные peer-адреса запрещены. Общий секрет не выдаётся
браузерам; отдельные credentials на час выдаются только подключённым участникам
через их WebSocket. Это не токены Spotify. Список ICE-кандидатов доступен
только двум участникам одной разрешённой пары. При остановке, смене хоста
или разрыве источника браузеры закрывают соединения и захват.

Оценка ёмкости всех комнат и длительных сессий ещё не выполнена.
