# Облегчение интерфейса

Изменения: неподвижная фотография с сохранённым размытием, растровая плитка
динамического тёмного зерна (~43 КБ, кешируемое имя с хешем), отсутствие
backdrop blur поверх анимированного фона. Зерно обновляется примерно 7 раз/с
вместо 29. Полосы визуализатора меняют transform вместо высоты.
Декоративные анимации приостанавливаются в скрытой вкладке.

Списки JSX и фильтр медиатеки мемоизированы. Обработчики сохранённых карточек
обращаются к актуальным действиям через ref, включая текущую ревизию очереди,
голос и доступ провайдера. Мобильные закрытые панели не монтируют карточки;
невидимые строки открытого списка используют content-visibility.
Таймер интерфейса обновляется раз в секунду; реальная позиция аудио, контроль
окончания, кроссфейд и синхронизация продолжают использовать точные значения.
Анализатор захвата обновляет meter напрямую, без перерисовки всего App.

Проверено в локальном браузере: 60 карточек очереди на десктопе, 0 в закрытой
мобильной панели, 60 после открытия; лайк переставляет карточку и отображает
собственный голос. Ошибок JS в этой проверке нет. Сборка и frontend-тесты проходят.

Процент снижения CPU/GPU и долгий прогон реального Spotify на слабых устройствах
не измерены. Spotify Embed/его worker и кодирование WebRTC имеют собственную
нагрузку; этот патч не удаляет их и не доказывает устранение всех тормозов.
