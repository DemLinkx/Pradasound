# Apple Music: экспериментальное подключение

Реализованы MusicKit JS v3, вход на сайте Apple, импорт личной медиатеки
страницами по 50 записей и оригиналы в общей очереди `apple_<catalog_id>`.
Для прослушивания каждый браузер использует собственную авторизацию MusicKit.
Чужая подписка и Music User Token слушателям не передаются. Кроссфейд
Apple Music не выполняется; переход по завершении управляется общей очередью.

Пока ключ MusicKit отсутствует, вход выключен. Проверки с тестовыми ответами
API подтверждают контракт, но реальный вход и полный трек ещё не проверены.

Для включения нужен Apple Developer с настроенным MusicKit и подписанный
developer JWT. Задайте `APPLE_MUSIC_DEVELOPER_TOKEN` в серверном `.env` и
пересоздайте контейнер API. Настройте используемые веб-домены у Apple.
Приватный ключ `.p8` в сайт, репозиторий и браузер не передаётся.
Developer JWT выдаётся браузеру для MusicKit через `/api/music/apple/config`;
это предусмотренная Apple модель. Персональный Music User Token сервер
хранит временно за случайным handle и не включает в события лобби.

Локальные записи без каталожного ID и треки длиннее 12 минут недоступны.
Официальные инструкции: https://developer.apple.com/musickit/
